# Security policy

Report vulnerabilities using GitHub's private vulnerability reporting feature
for this repository. Do not disclose exploitable details in a public issue.

Research packets may contain sensitive investment work. Grounded Alpha does not
transmit them, and contributions must preserve local-only operation unless a
future network feature is explicit, optional, and documented.

The project does not accept reports about inaccurate investment outcomes.
Grounded Alpha evaluates evidence hygiene and internal consistency; it does not
promise that a passing thesis is correct or profitable.
